# Full-Stack Web Development Resources

## Knowledge

- [MDN Web Docs: How the Web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/How_the_Web_works)
  Primary reference for HTTP request-response cycle and client-server architecture. Use for: grounding mental models of browsers and servers.
- [Microsoft Learn: Overview of ASP.NET Core Minimal APIs](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/minimal-apis/overview)
  Official guide to modern lightweight HTTP APIs in .NET. Use for: understanding how backend endpoints like `app.MapGet("/api/books")` work.
- [Microsoft Learn: Entity Framework Core Overview](https://learn.microsoft.com/en-us/ef/core/)
  Official EF Core documentation. Use for: understanding ORM, `DbContext`, and querying SQLite without raw SQL strings.
- [Angular Official Docs: Components Overview](https://angular.dev/guide/components)
  Official guide on Angular components, templates, and signals. Use for: learning how the UI displays and reacts to data changes.
- [SQLite Documentation: Distinctive Features of SQLite](https://www.sqlite.org/different.html)
  Official overview of SQLite's serverless, file-based architecture. Use for: understanding why SQLite stores data directly in a local `.db` file.
