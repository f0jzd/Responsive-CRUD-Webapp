Core Architecture Glossary

A fast lookup guide for foundational full-stack concepts encountered across Issue #1 and the Book Catalog project.

The Architecture Layers

Client (Frontend / Browser)
The interface running on the user's computer inside Google Chrome, Safari, or Firefox. Built with Angular and TypeScript in our project.
Server (Backend / Web API)
The background program waiting for requests over the network. It handles business logic and security. Built with C# and ASP.NET Core in our project.
Database (Storage)
The durable place where records survive even when servers or computers restart. In Issue #1, we use books.db, a single SQLite database file on disk.

Data Flow & Communication

HTTP Request & Response
The universal postal system of the web. The browser sends a Request (e.g. GET /api/books) and the server answers with a Response containing status codes and data.
JSON (JavaScript Object Notation)
The text format used to exchange structured data over HTTP. Both C# on the server and TypeScript on the client can effortlessly convert objects to and from JSON.
REST API Endpoint
A specific URL exposed by the backend where clients can ask for data or trigger actions (e.g. GET /api/books/3 asks for book ID 3).
ORM (Object-Relational Mapper) / Entity Framework Core
A translator library that allows developers to query and save database records using native C# objects and classes without writing raw SQL strings by hand.

Frontend Concepts

Single-Page Application (SPA)
A web application that loads once. When the user searches or navigates, the page does not reload completely; JavaScript just repaints the updated content.
Angular Component
A self-contained building block of UI combining an HTML template (what it looks like), TypeScript logic (how it behaves), and CSS styles.
Signal (State)
A reactive value container in modern Angular. When the value inside a signal changes, Angular automatically updates the exact parts of the screen that read it.
Client-Side Filtering
Searching and filtering data entirely in the browser's memory using JavaScript/TypeScript, giving users instant results as they type without asking the server again on every keystroke.
