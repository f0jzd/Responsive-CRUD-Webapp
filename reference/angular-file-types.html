Angular File Types & Conventions

A quick-reference cheat sheet for identifying and navigating Angular files in this codebase.

File Suffixes & Their Responsibilities

*.component.ts — The Visual Building Block
Defines a UI element (e.g. book-list.component.ts). Bundles the HTML template (what you see), CSS styles (how it looks), and TypeScript class (how it reacts to clicks or typing).
*.service.ts — The Data Messenger
A reusable helper class (e.g. book.service.ts). It contains no HTML. Its sole purpose is fetching data from the backend Web API over HTTP and providing it to components.
*.spec.ts — The Automated Safety Net
Unit and integration test files (e.g. book-list.component.spec.ts). Tests verify that components render properly and that search filtering works without manually clicking in a browser.
app.routes.ts — The Traffic Director
The URL router map. It specifies which component to display when the user visits a specific URL (for example: /books displays BookListComponent).
app.config.ts — The Application Blueprint
Configures global settings when Angular boots up, such as registering the HTTP client provider and router.
models.ts — The Data Shape Definitions
Defines TypeScript interfaces (e.g. interface Book) describing what properties a book possesses (id, title, author, description).
