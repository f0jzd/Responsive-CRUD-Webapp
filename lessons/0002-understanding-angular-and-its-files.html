Understanding Angular & How Angular Files Work

A hands-on breakdown of Angular components, file naming conventions, and how the frontend code in Issue #1 comes to life.

What Exactly Is Angular?

In a classic website from 2005, clicking a link meant asking the server to build a brand-new HTML page and reload the entire browser window.

Angular is a modern frontend framework that turns your website into a Single-Page Application (SPA). The browser loads the website once. From then on, Angular dynamically updates only the parts of the screen that need to change—without page refreshes.

The Mental Model: LEGO Bricks
In Angular, everything on screen is built from Components. Think of a component as an interactive LEGO brick containing its own look (HTML), its own brain (TypeScript), and its own style (CSS). You build complex apps by snapping small components together.

The Angular File Anatomy

When you inspect the frontend/src/app directory in our project, you will notice files ending in specific suffixes. Each suffix tells Angular and you what that file's job is:

  • book-list.component.ts: The component file. It displays the grid of book cards and handles search input.
  • book.service.ts: The service file. It makes HTTP calls to the .NET backend API to fetch book data.
  • book-list.component.spec.ts: The automated test file. It runs unit tests to ensure searching works properly.
  • app.routes.ts: The router map. It maps URL paths (like /books) to specific components.

1. The @Component Decorator

The decorator is the "ID badge" of the component. It tells Angular its HTML tag name (selector: 'app-book-list') and lists any extra tools or components it needs to use.

What Is a "Signal"?

In book-list.component.ts, you'll see lines like: 

searchTerm = signal('');
books = signal<Book[]>([]);

A Signal is like a smart variable with an alert system. When someone types in the search bar, searchTerm updates. Angular notices the change immediately and automatically re-calculates filteredBooks and repaints the screen. You don't have to write manual code to redraw elements!
