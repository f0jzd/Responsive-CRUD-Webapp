# Mission: Full-Stack Web Development Fundamentals (Book Catalog)

## Why
Build a foundational mental model and hands-on understanding of how modern full-stack web applications work end-to-end—from database persistence to backend APIs and interactive frontend views—starting with no prior backend or Angular experience.

## Success looks like
- Explain clearly how data travels from a SQLite database, through an ASP.NET Core Web API, across HTTP, into an Angular application, and onto the user's screen.
- Trace and understand the code powering Issue #1: the SQLite database (`books.db`), the EF Core `AppDbContext`, the `GET /api/books` endpoint, and the Angular `BookListComponent` with real-time search.
- Confidently inspect, run, and make small modifications to both the backend and frontend code with an intuitive grasp of how the pieces connect.

## Constraints
- Absolute beginner to backend (C#, .NET, databases) and frontend (TypeScript, Angular).
- Guard working memory strictly: introduce concepts one layer at a time with visual mental models before code syntax.
- Interactive, self-contained HTML lessons with immediate feedback loops and retrieval practice.

## Out of scope
- User authentication, passwords, and JWT tokens (deferred to Issue #3).
- Complex write operations or multi-table relational schema designs.
- Advanced performance optimizations or production deployment configurations.
